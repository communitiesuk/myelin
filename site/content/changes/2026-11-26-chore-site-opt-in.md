myelin opted into proj-site, so it now has a public site that follows the
project: an overview, a weekly weeknote, an entry for every pull request, a
timeline of what was explored, decided, built and shipped, and the open
issues that are coming next. Each pull request now carries its own short
entry, and a check makes sure none is forgotten.
