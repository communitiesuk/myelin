# Seeds

Undeveloped ideas for this project — "seeds" — live in two stores (see `docs/adr/0006-where-do-captured-ideas-live.md`):

- **GitHub issues tagged `seed`** — the shared store. **Read** these, and **write** new seeds here.
- **`docs/myelin.org`** — the maintainer's private backlog (gitignored, symlinked from `~/todo`). **Read** it for context; **never write** to it. Agent-generated captures go to a `seed`-tagged issue, not this file.
